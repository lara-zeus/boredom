# Zeus Boredom

use Boring Avatars as the default avatar provider in your FilamentPHP v3 application

## Features

- 🔥 configurable per panel
- 🔥 set Variant (marble, beam, pixel, sunset, ring or bauhaus)
- 🔥 Custom size
- 🔥 Custom colors
- 🔥 Square avatars
- 🔥 Name, email or username
