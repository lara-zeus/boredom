## Features

- 🔥 configurable per panel
- 🔥 set Variant (marble, beam, pixel, sunset, ring or bauhaus)
- 🔥 Custom size
- 🔥 Custom colors
- 🔥 Square avatars
- 🔥 Name, email or username
